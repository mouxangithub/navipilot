# navipilot — Project Instructions

**Package:** `com.mouxan.drivingassist`
**Tech Stack:** Java/Gradle (Android), Python (CarrotPilot side)

## Build & Test

- `./gradlew build`
- `./gradlew test`

## Code Style

- Follow existing patterns in the codebase
- Write tests for new functionality

## Architecture Overview

### App-side (Android)
| File | Lines | Purpose |
|------|-------|---------|
| `MainActivityUI.kt` | ~1500 | All UI composables + search dialog + address management |
| `MainActivityLifecycle.kt` | ~1100 | Startup self-check, lifecycle, Navi v2 init, data push loop |
| `MainActivityCore.kt` | ~900 | Core state, broadcast receivers, param client, network manager |
| `Navigation/` | — | v2 WebSocket client + stream manager + data models |
| `CarrotManDataModels.kt` | ~265 | CarrotManFields (44 UDP fields) |
| `AmapBroadcastHandlers.kt` | ~1300 | Amap broadcast parsing + mapping to CarrotManFields |

### CarrotPilot-side (Python)
- `carrot_man.py` — Main server (UDP 7706 receive, TCP 7709 route, HTTP 7713)
- `carrot_serv.py` — Service logic (SDI/TBT/route processing, update() entry point)
- `carrot_navi.py` — v2 WebSocket server (7714)
- `xiaoge_data.py` — TCP 7711 vehicle data broadcaster (simplified ~300 lines)

### Network Ports
| Port | Protocol | App → Pilot | Pilot → App |
|------|----------|-------------|-------------|
| 7705 | UDP | — | Device discovery broadcast |
| 7706 | UDP | 44-field nav data | — |
| 7714 | WS | v2 JSON streams (13) | — |
| 7711 | TCP | — | Vehicle real-time data |

## Key Implementations

### v2 Protocol Streams (NaviStreamManager)
| Stream | Status | Data Source |
|--------|--------|-------------|
| vehicle | ✅ | `vpPosPointLat/Lon`, `nPosAngle/Speed` |
| guidance_current | ✅ | `nTBTDist`, `nTBTTurnType` |
| guidance_next | ✅ | `nTBTDistNext`, `nTBTTurnTypeNext` |
| navigation_status | ✅ | Route active/idle state |
| route | ✅ | `nGoPosDist/Time` |
| speed | ✅ | SDI + road limit speed |
| lane_current | ✅ | `laneInfoList` |
| lane_ahead | ✅ | Same as lane_current (Amap no distinction) |
| traffic_signal | ✅ | Amap traffic light broadcast |
| app_status | ✅ | Foreground state |
| camera_state | ✅ | GPS position (map viewport) |
| crossroad | ✅ | TBT turn data infers junction |
| composition_state | ❌ absent (no data source) |

### Performance Fixes Applied
- `saveNetworkStatusToPrefs` → `Dispatchers.IO`
- `saveSpeedDataToPreferences` → `Dispatchers.IO`
- `migrateCoordinates` → `CoroutineScope(IO).launch`
- `loadNavHistory` → `LaunchedEffect` + `withContext(IO)`

## Known Limitations
- `composition_state` always absent (no image composition data from Amap)
- 7709 TCP route server not implemented (v2 WS stream covers route)
- `saveNavHistory` / `saveAddress` still on main thread (low frequency)
- AppOps `attributionTag` warning (AGP version limitation)
